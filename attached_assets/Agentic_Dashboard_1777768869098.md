\## 21. Security, privacy, and guardrails

\- do not store more personal data than needed

\- keep secrets outside repo

\- use Bitwarden-managed environment values

\- sanitize pasted text before agent processing

\- label AI outputs clearly

\- require human review before outbound actions

\- log approvals and rejections

\- use fallback responses when confidence is low

\- avoid using sensitive financial, medical, or protected data in prompts

\- include prompt injection checks on user-entered notes and imported text
